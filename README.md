# Порция — версия для GitHub Pages

Это самостоятельная статическая версия приложения «Порция», подготовленная из предоставленного `grok-workspace.zip`. Не требует Node.js, сборки, базы данных или сервера: откройте `index.html` либо опубликуйте папку через GitHub Pages.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите `index.html` и `README.md` в корень репозитория (не загружайте только ZIP как единственный файл).
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/(root)`, нажмите **Save**.
6. Дождитесь публикации — адрес появится в этом же разделе Pages.

## Что работает

- дневник по датам и приёмам пищи;
- каталог базовых продуктов и поиск;
- расчёт калорий и БЖУ по граммовке;
- создание пользовательских продуктов;
- дневные цели калорий, БЖУ и воды;
- календарь, недельная статистика и профиль;
- экспорт и импорт резервной копии JSON;
- локальное хранение данных в `localStorage` браузера.

## Ограничения статической версии

- Данные находятся только в текущем браузере и на текущем устройстве. Они не синхронизируются между устройствами; регулярно делайте экспорт JSON.
- Распознавание еды по фотографии, внешние AI/API-функции, учётные записи и серверная синхронизация не включены: GitHub Pages не запускает серверный код.
- Каталог — встроенный базовый набор продуктов, а не подключённая онлайн-база. Значения питательности ориентировочные.
- Чтобы сбросить onboarding и проверить стартовый экран, используйте профиль → «Сбросить все данные».
